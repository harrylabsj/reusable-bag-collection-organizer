# Reusable Bag Door-Station Organizer

Create a printable reusable bag collection map and weekly reset card — sort existing bags by size, assign safe door stations, and build grab-and-return rules without purchases.

## What it does
- Sort bags by function (large totes, insulated, produce, folding) and assign safe storage stations
- Create grab rules for different trip types: grocery runs, quick errands, cold-item trips
- Build weekly reset cards to keep bags from piling up in cars, closets, and entryways

## Example scenarios

**1. 家里囤了30个帆布袋怎么办**
> 👤 每次买奶茶/书店/品牌活动就送帆布袋，现在家里堆了三四十个。扔了可惜，留着占地方。怎么系统处理？
> 🤖 帆布袋整理方案——第一步：分类淘汰（留5个最好看+5个质量最好的实用型，其余洗净叠好）；第二步：利用渠道（闲鱼打包卖"福袋"10元5个、公司团建捐社区当环保袋、剪刀裁开做收纳分隔板）；第三步：日常循环（玄关收纳盒集中放，出门随机拿用完放回）；第四步：源头控制（买奶茶主动说不要袋子、自带无纺布折叠袋）。关键：超过15个就是负担，保持5-10个合理库存。

**2. Log a lent bag with reminder**
> 👤 Log that I lent my foldable nylon bag to a friend on 6/15. Remind me in 2 weeks to check if it's returned.
> 🤖 Record created with lent status, borrower note, and a reminder scheduled for 6/29. Bag is excluded from rotation until returned.

**3. Track usage and cleaning cycles**
> 👤 Which bags have been unused for over a month? Do any need washing?
> 🤖 Report listing idle bags (>30 days unused) and those exceeding cleaning-threshold cycles. Suggests rotation order to even out wear.
